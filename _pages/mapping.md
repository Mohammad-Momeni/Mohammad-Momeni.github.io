<article class="case-study section-shell"><a class="text-link" href="{{ '/' | relative_url }}#work">← Selected work</a><p class="eyebrow">Robotics / Geometry / Webots</p><h1>From readings<br>to <em>structure.</em></h1><p class="case-intro">A split-and-merge mapping experiment: using geometry to turn a robot’s distance-sensor observations into a more compact description of its surroundings.</p><ul class="tags" aria-label="Technologies"><li>Python</li><li>NumPy</li><li>Webots</li><li>Matplotlib</li></ul><figure class="case-figure"><img src="{{ '/assets/images/mapping.webp' | relative_url }}" width="1000" height="700" alt="Mapping output showing the estimated line segments from the split-and-merge experiment"><figcaption>Output from the project. Sensor observations are processed into line segments.</figcaption></figure><div class="case-content"><section><h2>The question</h2><p>A distance sensor gives individual observations. A map needs structure. This project explores how to move from one representation to the other, using the robot’s pose and a geometric line-fitting procedure.</p></section><section><h2>The approach</h2><ol><li><strong>Interpret the sensors.</strong> Convert sensor outputs into distances using the lookup table and linear interpolation.</li><li><strong>Place the observations.</strong> Use the robot’s position and heading to express measurements as points in the environment.</li><li><strong>Split.</strong> Find the point with the greatest perpendicular distance from a candidate line; split a group when its deviation exceeds a threshold.</li><li><strong>Merge.</strong> Combine compatible segments to simplify the representation.</li></ol></section><section><h2>The engineering</h2><p>The Webots controller brings together differential-drive kinematics, compass-based heading estimation, distance-sensor interpretation, and the split-and-merge procedure. NumPy and Matplotlib support the numerical work and inspection of the output.</p><p>I’m interested in this kind of problem because each layer matters: the interpretation of a sensor, the coordinate system, the geometry, and the final representation.</p></section></div><a class="text-link" href="{{ '/' | relative_url }}#work">Back to all projects ↗</a></article>
